# v0.23 无式斜向修复测试版

安装包：KOF98-K12s-v0.23-无式斜向修复.apk。与 v0.22 使用同一签名，可覆盖安装。

## 这次查到的问题

旧代码用「前一个方向持续了多久」判断要不要保护斜向。先按住下，再迅速滑过左下时，这个条件会失效，左下可能只送到游戏一帧。

本次收到的记录中，约第 20 秒的第一圈先按下 57 毫秒，随后左下仅经过 11 毫秒；第二圈先按下 81 毫秒，左下经过 17 毫秒。方向顺序是完整的，但两个左下在游戏输入中都只持续一帧。

新版本确保每个斜向至少经过两次游戏采样，左右两侧采用相同规则。已经连续保持的斜向不会在离开时额外拖延。暂停、取消触摸和布局变更仍立即清空输入。

## 验证结果

- 将原记录的 2,549 个触屏采样按原顺序重新送入旧代码，3,467 帧输出与日志逐帧一致，复现过程没有改动手指轨迹或按拳时间。
- 同样的触屏采样经修复后，46 帧输出发生变化；触点对应的当前方向和按键判定保持一致。
- 在独立的桌面游戏核心中，以草薙京站在对手右侧、能够正常使用超必杀的相同初始状态，回放约第 20、21、27、35 秒的四段输入：旧代码均未出无式，修复后均出了无式。
- 约第 34 秒的另一段输入，按 A 时仍在下方向，最后的左比 A 晚约 51 毫秒。这段输入在修复后仍未出无式。
- 主机回归、144 项触屏回放场景、31 项 Android 框架自动化测试，以及 APK 签名和对齐校验通过。

上述出招验证使用本地桌面核心，不等同于已在这台手机上复测；实际手机上的角色状态、能量和对手动作仍会影响出招。

## 怎么复测

进入游戏后按平时方式测试右侧的 ↓↙←↓↙←＋A/C，最后一次到左时再按拳。可以继续通过「设置/暂停 → 输入调试」录制并导出。成功和失败的尝试放在同一段记录中，方便继续对比。

输入调试仍默认关闭，单次最多 2 分钟；请先导出，再退出应用。
