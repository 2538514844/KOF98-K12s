# v0.26 MAX 键

攻击键上方新增金黄色圆形 MAX 键。默认直径为普通 A/B/C/D 的 68%，可在「设置 → 按键布局」中选择「MAX 爆气（A+B+C）」移动和调整大小。

按 MAX 等同于同时按住 A+B+C，松手即释放；MAX 和 A、B、C 会一起亮起。是否能爆气仍由游戏内模式、能量和角色状态决定。MAX 可以与摇杆或另一根手指按住的攻击键同时使用，松开 MAX 不会松开其他手指按住的键。

手指从普通攻击键滑过 MAX 时，保留原攻击手指的角色；需要直接落在 MAX 上才能按下。按住 MAX 后滑出其圆形区域会释放，滑回会再次按下。

## 升级兼容

沿用原签名，可直接覆盖安装。旧版的八个控件坐标、尺寸继续使用，MAX 作为第九个控件加入。如果原布局占据 MAX 的默认位置，会在附近寻找空位，原控件不需要重新排列。新布局以版本 2 保存，仍能读取版本 1 的八项配置。

- 用户此前无式记录的 3467 帧输入输出与 v0.23 修复版逐字节一致。
- APK v2/v3 签名、16 KiB ZIP 对齐、arm64 架构，以及与 v0.25 相同签名检查通过。
