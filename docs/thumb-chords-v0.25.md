# v0.25 单拇指组合键修复

安装包：KOF98-K12s-v0.25-单拇指双键修复.apk。与 v0.24 签名相同，可覆盖安装。

## 本次原因

用户确认双指分别按键能同时亮起，单根拇指不能。v0.24 依赖两个圆形触控区域重叠，按之前上传的 2400×1080 布局计算，A+B 和 C+D 沿两键连线的重叠宽度只有约 4.54 像素。此前只测精确中点，未覆盖手指偏移，导致实际操作仍难命中。

按钮高亮使用与游戏输入相同的本地按键值。此次已通过 Android Canvas 像素测试验证两键同时亮起、移回单键及松手后的变化。

## 修复与使用

扩大单根拇指的组合键判定区域。按上述布局，沿两键连线的双键区域宽度约为 60.84 像素；按键内侧 75% 半径区域仍判定为单键。单键外侧的独立触控范围不扩大。

拇指落在 A、B 之间，或 C、D 之间，即可同时按下相邻两键。稍微偏离中点也能识别；落在某个键中心仍只按该键。分别使用多根手指也可以组合按键。自定义布局若把两键分得过远，需要调整间距或使用多指。
