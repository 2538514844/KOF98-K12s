# v0.24 组合按键测试版

安装包：KOF98-K12s-v0.24-组合按键修复.apk。与 v0.23 签名相同，可覆盖安装。

## 怎么按

- 多根手指分别按 A、B、C、D，可以同时生效；松开其中一根，其他仍按住的键继续生效。
- 单根拇指按在相邻两键的共同触控区域，也会同时按下两键。默认布局可以先试 A+B、C+D 的交界处。
- 点按键中心仍是单键。拇指从交界处移回某个键中心时，只保留这个键。
- 自定义布局把两键拉得很远时，不存在共同触控区，需要双指分别按键，或在按键布局里调整间距。四键同时按使用多指。

## 查到并修复的问题

旧代码对一个触点只选择最近的一个攻击键，即使触点落在两个按键的共同触控区域，也会丢掉另一键。本版将共同触控区域内的按键一起送给游戏，并保留按键中心的单键区域，避免自定义大小和间距后点中心误触组合键。

多指分别按键的旧逻辑在本地回放中能正常合并。本次补充了所有 15 种非空按键组合、摇杆加四个攻击键、触点顺序变化和分别松开的验证；尚不能据此排除实际手机的触摸上报问题。
